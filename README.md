# Умножайка — замок телефона с таблицей умножения

С 15:00 до 07:00 вместо телефона показывается замок. Чтобы открыть телефон, ребёнок решает примеры.

## Как это работает
- Ребёнок выбирает время: **15 / 30 / 45 / 60 минут**. 1 пример = 3 минуты, поэтому 30 минут — это 10 примеров.
- Примеры из таблицы умножения (от 2 до 10) появляются по одному, **на ответ 5 секунд**.
- **Не успел** — серия начинается заново.
- **Ответил неправильно** — серия начинается заново, а награда уменьшается на **2 минуты** (30 → 28 → 26…). Штраф копится, пока ребёнок не решит серию до конца. Если вернуться в меню и выбрать другое время, штраф не снимается.
- После ошибки на 2 секунды показывается правильный ответ («Запомни: 7 × 8 = 56»).
- Примеры, в которых ребёнок ошибается, попадаются чаще.
- За минуту до конца — вибрация и сообщение «Осталась 1 минута».

## Секретный код родителя: **2893**
- Наберите его **вместо ответа в любом примере**: примеры и штраф сбросятся, откроется меню родителя («Открыть на 30 мин / 1 час / 3 часа», «Выключить до 07:00», «Настройки»).
- Он же подходит к кнопке «👤 Родитель» на замке и к экрану настроек.
- Код можно поменять в настройках.

## Как получить APK (бесплатно, через GitHub, ~5 минут)
1. Зарегистрируйтесь на github.com (если ещё нет).
2. Нажмите **New repository** → любое имя, например `umnozhaika` → **Private** → **Create repository**.
3. На странице репозитория выберите **uploading an existing file** и перетащите **всё содержимое** распакованной папки `MathLock`. Папку `.github` нужно перенести обязательно: она скрытая, поэтому включите показ скрытых файлов. Нажмите **Commit changes**.
4. Откройте вкладку **Actions**: сборка запустится сама и займёт 3–5 минут. Если она не запустилась, выберите *Build APK* → **Run workflow**.
5. Когда появится зелёная галочка, откройте сборку и внизу в разделе **Artifacts** скачайте `Umnozhaika-apk`. Внутри zip-архива лежит **Umnozhaika.apk**.

Второй вариант: открыть папку в Android Studio и выбрать Build → Build APK(s).

## Установка на телефон ребёнка
1. Перекиньте `Umnozhaika.apk` на телефон и откройте его. Разрешите «установку из неизвестных источников».
2. Откройте «Умножайку» и введите код **2893**.
3. Нажмите каждую красную кнопку в разделе «Разрешения», пока все не станут ✅:
   - **Поверх других окон** — обязательно.
   - **Уведомления**, **Без ограничений батареи**.
   - **Защита от удаления** (администратор устройства).
   - **Автоматическое время** — если его выключить, замок действует круглосуточно, так что перевести часы не получится.
4. Задайте свой PIN (по желанию), проверьте настройки и нажмите **Сохранить**.
5. Включите переключатель **«Защита включена»** и нажмите **«Проверить замок»**.

**Xiaomi / Redmi / POCO / Huawei / Honor / Oppo / Realme / Vivo:** дополнительно включите для приложения «Автозапуск», а в разделе «Батарея» выберите «Без ограничений». Иначе система может выгружать замок.

На Android 13 и новее, если какое-то разрешение недоступно (серое): Настройки → Приложения → Умножайка → ⋮ → «Разрешить ограниченные настройки».

## Что важно знать
- Обычное приложение не может по-настоящему заменить системный экран блокировки. «Умножайка» показывает полноэкранный замок поверх всего, и снять его без решения примеров или кода нельзя.
- Пока телефон разблокирован (в заработанные минуты), упорный ребёнок теоретически может зайти в Настройки → Приложения и «Остановить» приложение. Тогда замок вернётся только после перезагрузки или открытия «Умножайки». Чтобы закрыть и эту лазейку, нужен режим «владельца устройства» (Device Owner) — это можно сделать во второй версии.
- Кнопка «📞 Позвонить» на замке открывает набор номера родителя (номер задаётся в настройках) и снимает замок на 2 минуты. Её можно использовать не больше 5 раз в день, все звонки видны в статистике. Экстренный вызов на большинстве телефонов: 5 раз нажать кнопку питания.
- В настройках есть статистика за день: сколько минут заработано, сколько было ошибок и какие примеры даются труднее всего.

| Выходные (сб, вс) весь день | выкл |
| Множители | от 2 до 10 |
| Секунд на ответ | 5 |
| Минут за пример | 3 |
| Штраф за ошибку | 2 мин |
| Варианты времени | 15, 30, 45, 60 |
| Лимит в день | без лимита |
